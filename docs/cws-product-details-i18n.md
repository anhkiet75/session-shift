### `en` — English (source)

Key Features:

🔐 Per-tab cookie isolation — no cookie sharing between profiles
👥 Named, color-coded profiles — create, rename, recolor, duplicate
🌍 One global profile list — searchable, shared across every site
🔗 Auto-inherit for linked tabs — tabs opened from a link keep the opener's profile
🖱️ Right-click any link → "Open in Session" to pick a profile
🏷️ Toolbar badge + tinted icon show the active profile at a glance
📁 Optional native Chrome tab groups, one per profile
⌨️ Keyboard shortcuts — open the popup, cycle profiles
🎨 Dark / Light / System theme
🌐 55 languages, with right-to-left support
🔒 100% offline — no analytics, no external services, no tracking

Take control of your browser and manage accounts smarter with SessionShift.
